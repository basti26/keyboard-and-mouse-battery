# 无线键鼠电量

在 Windows 托盘查看鼠标和键盘电量，无需安装 Python。

## 支持型号

- 鼠标：VXE 蜻蜓 R1SE+
- 键盘：珂芝 K75

## 怎么用

1. 下载 [无线键鼠电量.exe](./无线键鼠电量.exe)，保存到固定文件夹，双击运行。
2. 在任务栏右下角找到红蓝圆环图标。如果藏在“∧”里，把它拖到时钟旁即可常驻显示。
3. **左边红色半圈是鼠标，右边蓝色半圈是键盘**，亮起的弧长表示剩余电量。悬停或右键图标可查看具体百分比。
4. 程序每 1 分钟自动刷新。双击图标、打开右键菜单或点击“立即刷新”也可以更新电量。
5. 需要开机自动运行时，右键图标，勾选“开机启动”。开启后请勿移动 EXE；如果移动了，重新运行并开启自启即可。

没有读到数据时，会等待约 1.5 秒，仅对读取失败的设备主动重试一次；仍无数据则显示“未读取”，等待下次刷新。电量低于或等于 10% 时会提醒。右键选择“退出”可关闭程序。

卸载时，先取消“开机启动”，再退出程序并删除文件即可。
